# 中心市街地記事の挿絵追加

対象: https://bearworks.uk/labs/hachioji-city-center

## 変更範囲

第4弾記事の冒頭に、商店と集合住宅、街を歩く人々を描いたAI生成イラストを追加する。前作に合わせPCでは文章と挿絵を左右に、スマホでは上下に配置し、実在する景観・人通りを再現したものではない旨を表示する。画像の代替テキストを付け、SNS共有画像とArticle JSON-LDにも同じ画像を設定する。本文の分析・数値は変更しない。

画像は既存の第2・第3弾の画像を作風の参考にして、built-in imagegenで新規作成。保存先は `public/images/hachioji-city-center/hero-illustration.webp`。画像生成の指示: 八王子の中心市街地を連想する、商店・集合住宅・歩行者と遠景の緑を組み合わせた、明るく落ち着いた日本の街並みの横長イラスト。特定の建物や実際の人流を表すものにせず、文字やロゴを入れない。

## 公開と検証

実装済みのプレビューをPCとスマホで確認し、挿絵の読込、横幅、代替テキスト、OGPとJSON-LDを確認する。公開を含む計画承認後、対象のみcommit/pushしPRを作成、必須Workers buildで既存のページ検証を通す。main merge後は同一treeの本番用Linux artifactを使用して既存Workersへデプロイし、復旧先を記録したうえで公開記事と画像、表示、広告/Access境界を確認する。本文のデータ再集計は行わない。追加のCIや再検証は失敗・変更・具体的懸念がある場合に限る。
