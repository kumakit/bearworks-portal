## 確認済みの定義と数値

### 人口

2025年度フォローアップp.1の「中心市街地区域」人口: 2022/2023/2024/2025年の各12月31日、34,183 / 34,401 / 34,489 / 34,769人。差は218 / 88 / 280人、2022→2025は586人。自然・社会増減は「測定不能」の年があり、掲載の増減項目とストック差を機械的に結び付けない。

基本計画本文p.5–6には2012–2021年の人口・市全体との同日比較表がある。中心市街地は27,227 / 27,443 / 27,981 / 29,267 / 29,383 / 30,121 / 30,921 / 32,256 / 33,082 / 33,232人。ただしp.6の中心市街地合計は17町丁の数値を掲載しており、p.66の計画区域には一部包含の町丁がある。最新フォローアップ人口を115ha境界内の厳密な人口と断定する根拠は、現時点で確定していない。

**採用方針**: 最新系列は「市フォローアップ掲載の中心市街地人口」と明記する。115haで割った人口密度・町丁人口の面積按分は作らない。旧計画系列との定義一致を確認後だけ接続し、不明なら別パネルにする。2016/2026年9月末の前作人口を12月末系列へ接続しない。

### 歩行者通行量: 重みと地点集合が重要

2025年度フォローアップp.6の画像表は **平休日平均 = (休日23地点合計×2 + 平日23地点合計×5)÷7、四捨五入** と明記。単純な2日平均ではない。

| 年度 | 休日23地点合計 | 平日23地点合計 | 公表の加重平均 |
| --- | ---: | ---: | ---: |
| 2023 | 117,859 | 116,530 | 116,910 |
| 2024 | 124,909 | 112,259 | 115,873 |
| 2025 | 129,272 | 114,530 | 118,742 |

2022年度の加重平均114,103、2018–2021年度の基準平均117,769。後者は単年やコロナ前だけの基準ではない。2025年の休日は2024比4,363増、平日は2,271増。これらから加重平均を再現できる。調査地点間で同じ人が複数回数えられ得るので、ユニークな来街者数と呼ばない。

2025年度歩行量報告書の本文p.1では調査対象は**32地点**、中学生以上、乗車中の自転車を除外、目視カウンターで方向・時間・男女別、9–22時の13時間。調査日は2025-11-23(日)と11-25(火)。地点名変更・13-1/13-2とその合計行に注意する。

同報告書p.18–19に2011–2025年度の地点別過去推移があり、直近3年より遡れる。2014–2015年等には欠測地点があるため、比較可能な固定集合を確認する。主分析は計画の23地点、残る駅通路等を含む全32地点は補助分析として明確に区別する。

全32地点の2025年合計は休日486,847、平日457,386。2024年は463,372 / 471,729。**23地点では平日増、32地点では平日減という違いがある**。集合が異なるので矛盾として混ぜない。報告書p.6本文の平日減少14,661人に対し、表と引き算は14,343人で一致しない。派生値は元の人数から計算し、原文の増減値を無批判に採用しない。正式処理では全地点・個票・過去表・フォローアップの対応を検算する。

### 空き店舗

基本計画p.22: 2018/2019/2020/2021年度の1階路面の空き店舗は122 / 100 / 103 / 86。募集あり・なしの合計も一致する。2025フォローアップp.14: 2021–2025年度86 / 68 / 72 / 63 / 62。巡回・目視、2025年11月、事業活用の可能性があるが活用されていない路面店舗。空き店舗率や全フロアの空室数ではない。

同p.14は入居のほか、募集なし物件の解体・マンション建設を記述する。空き店舗数の減少だけで売上増・店舗総数増・商業の繁栄とは言わない。「マッチング支援ネット」の1か月未使用という制度定義を調査の定義へ無断で移植しない。2018–2025の連続グラフは調査範囲・定義の一致を正式処理で確認してから確定。

### 補助指標・住宅

施設来場者数は2021–2025年度34,601 / 62,546 / 88,398 / 88,340 / 87,165人/年。対象は八王子宿・CHITOSEYA・YOTTETTE・まちはぐ。CHITOSEYAは2022年6月開業で初年度10か月。対象施設・稼働期間が違うため基準比を単純に人出回復の指標にしない。原資料の小表の「人/日」表記は見出し・調査期間と食い違い、年の延べ来場者として注記を残す。

建築計画概要書の市案内は窓口申請・個別物件特定を要し、現況や竣工を証明する資料ではない。オンラインで区域内新築棟数・戸数を網羅できる一次データはまだ見つかっていない。個別再開発は工事完了・戸数・区域と時点を確認した事例だけに限定。古い開発や計画中の開発を「この数年の竣工」にしない。

## 区域と地図

基本計画p.66は約115haの区域図と境界説明を掲載。一部包含の町丁があり、マッチング制度ページとは八幡町の全部/一部の書き方も異なる。資料の年代・用途を優先し、図を勝手に正確なGIS境界へ変換しない。今回確認した入口と市GIS紹介では、利用条件まで確認した115haのダウンロード可能な幾何データは得られていない。「存在しない」とは断定しない。

主案は地点別の増減棒グラフ＋表。地点図を追加する場合は現地の調査断面を原図と照合し、測地系・位置精度・基図利用条件・出典を記録した点だけを描く。未確認の境界・地価地点・町丁面塗りで歩行量の範囲を代用しない。

## Phase 0 判定

3本柱の記事は制作可能な見込み。主分析を「公式115haに関連する市公表指標」とし、人口の厳密な地理範囲は未確定と表示する。長期系列の定義照合・全地点の検算・住宅事例の確認は正式分析に残す。115haの厳密な人口や全新築棟数がないことを理由に、周辺人口や広告データで穴埋めしない。記事の結論はまだ確定しない。

## 承認後の正式照合（2026-10-27）

- `prepare_sources.py` で歩行32地点×2016–2025年×2日種を抽出。13-1/13-2の小計行を除外し、全32地点合計20値が公表値と完全一致。2023/2024版の過去行も全地点・全期間で一致し、2025全32地点の個票の平日/休日合計とも一致した。
- 23地点の2016年度指標124,297、2025年度118,742。2025年は23地点の平日+2,271、全32地点の平日−14,343。年度ごとに調査日が異なり、経路追跡や年間人流ではないことを本文に反映。
- 2023年度No.12の休日はエレベーター不具合で12月3日に再調査されていた。23地点にNo.12は含まれないが、全32の比較時にはこの例外を明記する。
- 公表基準117,769は、四捨五入済みの2018–2021年指標の平均117,768.5を四捨五入すると再現する。丸め前の値の平均では117,768となり、1人相当の違い。公表基準を勝手に修正せず、丸め順序をmanifestと本文へ記録した。
- 人口・空き店舗の旧新系列同一性は一次資料だけで確定できず、承認済みの別パネルを採用。人口密度・系列境界をまたぐ増減率は生成しない。
- 住宅の市計画p.7は「建設予定戸数（延べ）」の累計で、完成戸数として不採用。近年の完成総数は未確認と明記する。公式115ha境界の正確な位置・利用条件が未確定のため地図は採用せず、実際の調査地点別の増減棒グラフと表で示す。
- Lunaが原資料の集合・年次合計と実装差分を読み取りレビュー。司令塔が抽出コードの合計/元表/個票照合と本文・表示を直接確認した。Critical/Majorの指摘なし。
