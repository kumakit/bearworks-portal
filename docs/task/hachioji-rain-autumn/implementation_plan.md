# 八王子シリーズ第7・8弾 制作計画

作成日: 2026-10-04。ユーザーは会話中の企画案を承認し、第7・8弾の制作を指示した。

## 目的と範囲

- 第7弾 `/labs/hachioji-rain`: 八王子と東京都心の降水日数、降水量、季節性、上位5日の集中度、同日降水の対応を図で読む。
- 第8弾 `/labs/hachioji-autumn`: 八王子の9〜11月について、気温帯ごとの日数と年変動を比較。「秋の長さ」と定義上の日数を区別し、閾値を変えた感度分析を載せる。
- 両記事とも公開観測の固定原本、取得条件、品質・均質性情報、検算、図の数値表、確認問題を残す。
- アプリのAPI、既存6記事の固定データ、本番設定は変更しない。新たな常設分析サービスやStreamlitアプリは作らない。

## データ設計（集計前に固定）

気象庁 obsdl の八王子 a0366 と東京 s47662。2009-01-01〜2025-12-31の日平均/最高/最低気温・日降水量を同じ取得範囲で保存する。2026年は未完了年のため含めない。対象の気温・降水量は観測値を用い、再解析で補間しない。

主集計は品質8（正常値）のみ。品質5を追加した感度分析も別記。品質4/2/1/0を0へ変換しない。全日の日付被覆を確認する。均質番号は地点・要素ごとに確認する。同じ取得の中で番号が一定の期間だけを比較する。

雨: 東京移転後の2015〜2025年を候補とする。両地点で365/366日すべての降水量が正常値である共通年を年平均/月平均/集中度/分割表の主解析へ採用し、除外年は一覧化する。年を同じ重みで平均。閾値は日降水量1mm以上（雪を含む）。0.5/1/5/10mmの閾値別日数を感度比較する。降水日の平均雨量はその条件で抽出した量だけを分子に使う。上位5日の雨量は観測値として保持し、自動除外しない。条件付き割合の分母は該当する地点で降水した日だけ。

秋: 八王子2009〜2025年の9〜11月（各91日）を候補とする。主指標は日平均気温15℃以上25℃未満の日数で、体感快適性・紅葉・暦上の秋を直接測るものではない。14〜24℃、16〜26℃の定義も比較する。正常値が91日揃う秋のみ年別の完全値として扱い、欠測秋は図で欠測を明示する。初め5年（2009〜2013）と終わり5年（2021〜2025）の採用年平均を比較し、採用数を明記。中間の年も全て可視化する。開始/終了日の差や連続期間とは解釈しない。長期気候変動や因果関係は断定せず、検定/p値/将来予測を行わない。東京の比較を載せる場合は2015年以降の同日・同年を使う。

## 実装境界

公開固定原本とmanifestを `data/hachioji-rain-autumn/` に保存。オフライン生成器は `scripts/` に置き、記事表示は検証済みのJSONだけを読む。既存Portal内のheat/chillと同じ一度きりの記事用生成スクリプト構成。Apps側の常設分析パイプラインを移植/改変しない。

追加対象: 2ページ、共通図表/シリーズ導線、2固定bundleとlock、取得/生成/検証スクリプト、site-contentと一次データ分析一覧、制作記録。
ロールバック: 追加ページ/登録のみ取り下げる。既存bundleは変更しない。
