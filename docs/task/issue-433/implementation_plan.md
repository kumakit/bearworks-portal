# 第6弾「八王子は国際的になってきている？」実装計画

八王子市の外国人住民の人数、総人口に占める割合、国籍・地域の構成を図表で示す。公開先は `/labs/hachioji-international`。第5弾と相互リンクし、同じ配色・レイアウトと、新たに制作した冒頭イラストでシリーズとして読めるようにする。

## 確認したデータ

- **人数と総人口比**。東京都の月次住民基本台帳CSVから、2013～2026年の各10月1日の八王子市の14行を取得。各年で総人口＝日本人人口＋外国人人口を検算する。2013年は8,997人／563,895人（1.60％）、2026年は19,961人／559,320人（3.57％）。外国人の集計制度が2012年に切り替わったため、2013年を起点とする。 [東京都の月次住民基本台帳](https://www.toukei.metro.tokyo.lg.jp/juukim/jm-index.htm)
- **国籍・地域の構成**。東京都の10月表と八王子市の2026年9月末表で、市内の総数と公表区分の人数が一致した。比較対象の5区分（中国・フィリピン・ベトナム・ネパール・ミャンマー）は、2013～2026年の都の14ファイルすべてで同じ名称で個別掲載されていることを確認した。残りは毎年「全体から同じ区分の合計を引いた数」として再計算し、原表の「その他」と区別する。「韓国・朝鮮」と「韓国」のラベルは長期の折れ線へ接続しない。原表の掲載区分と「その他」の合計も、全14年の外国人住民総数と一致した。 [東京都の外国人人口](https://www.toukei.metro.tokyo.lg.jp/gaikoku/2026/ga26010000.htm)・[八王子市の主要国籍・地域別人口](https://www.city.hachioji.tokyo.jp/hachiouji/jinko/006/p037126.html)
- **近隣市**。2026年10月1日現在の東京都の同一住民基本台帳表で、八王子・町田・立川・日野・府中・青梅を比較する。八王子は19,961人・3.57％、立川は6,876人・3.66％。人数と総人口比を並べ、自治体の順位を一般化しない。 [東京都の2026年10月表](https://www.toukei.metro.tokyo.lg.jp/juukim/2026/jm26010000.htm)
- **在留資格は別図**。2025年4月の市議会資料では、留学26％、永住者25.6％、技術・人文知識・国際業務9％。原資料の丸めを保ち、市の同資料の時点を明示する。在留資格「留学」には日本語教育機関の学生等も含み得る。大学の外国人留学生数や第5弾で掲載した市内大学等の在籍者数から換算することはできない。現段階で同一定義の複数年系列は未確定。 [八王子市議会資料](https://www.city.hachioji.tokyo.jp/contents/shigikai_1/gikainokatudou/iinnkai/soumukikaku/p035918_d/fil/02_zaijugaikokujin.pdf)

## 実装と検証

1. 取得URL、基準日、取得日、出典、集計対象を固定データに記録する。小規模な取得・変換スクリプトを用意し、年の連続性、人口の内訳、国籍別合計、作り直した残余、分母、近隣6市の値を検算する。欠損があれば明示し、ゼロで補わない。
2. 人数と総人口比、国籍・地域の構成、近隣6市の比較、在留資格の補助図を掲載する。図表には基準日・単位を表示し、表でも値を参照できるようにする。市全体と市単位の集計を使い、町丁単位の国籍別表示は設けない。
3. Antigravityには公開資料と検算済みの値で一般向けの日本語初稿を依頼する。前回と同じ個人向けプランの基本枠を使い、そのセッションでの追加クレジットへの切替を無効にする。国籍から個人の属性を推測したり、人口構成で地域交流の進展を断定したりしない。
4. 前作の紺色ヘッダーと3:2画像、要点カード、モバイル配置を踏襲する。架空の八王子の街並みを題材に新しい画像を制作し、人物の国籍を見た目で示唆する記号は使わない。公表資料の数値を独自集計し、画像や原表のレイアウトは転載せず、各出典と加工を記す。 [東京都のサイトポリシー](https://www.toukei.metro.tokyo.lg.jp/homepage/site-policy.htm)・[八王子市の著作権案内](https://www.city.hachioji.tokyo.jp/987/p012154.html)
5. 第5弾、Labs一覧、サイトマップ、canonical、OGPを更新する。データ検算、既存記事の回帰、PCとスマホでの表示、Linux Workers CIを確認する。PR・本番公開は第5弾と同様に対象コミットと復旧先を確認し、リポジトリの公開手順に従う。
