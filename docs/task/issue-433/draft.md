# 八王子は国際的になってきている？

## 導入

第5弾では、八王子市内の大学・短大・高専で学ぶ学生の姿を見ました。では、街全体の住民構成はどう変わったのでしょうか。東京都の住民基本台帳（各年10月1日）と八王子市議会資料をもとに、外国人住民の人数、国籍・地域の構成、在留資格を見ていきます。 [第5弾「八王子はまだ学生の街？」](https://bearworks.uk/labs/hachioji-students)

## 主な発見

### 1. 外国人住民は13年間で10,964人増、総人口比は3.57％へ

2012年の制度変更をまたいだ比較はできないため、各年10月1日の住民基本台帳で2013年と2026年を比べます。八王子の外国人住民は2013年の8,997人／総人口563,895人（1.60％）から、2026年は19,961人／総人口559,320人（3.57％）へ10,964人増えました。日本人住民は2013年の554,898人から2026年は539,359人へ減っており、総人口に占める外国人住民の割合が高まっています。

### 2. 中国籍の住民は増え、構成比は下がった

同月の国籍・地域別表で2013年から2026年を見ると、中国は3,715人から6,400人に増え、外国人住民全体に占める割合は41.3％から32.1％に下がりました。同じ期間に、ベトナムは198人から2,232人、フィリピンは1,043人から1,633人、ネパールは239人から1,614人、ミャンマーは27人から1,077人に増えました。全14年で同じ名称で掲載されたこの5区分を比較し、残りは外国人住民の総数から5区分の合計を引いて求めました。残りは2013年に3,775人、2026年に7,005人です。ここで分かるのは、公表された区分ごとの人数と割合の変化です。

### 3. 6市比較では人数が最多、割合は2番目

2026年10月1日の共通断面で近隣6市に限定して比較すると、八王子19,961人・3.57％、町田12,137人・2.81％、府中6,987人・2.65％、立川6,876人・3.66％、日野4,616人・2.44％、青梅3,824人・2.98％です。八王子は人数で6市最多ですが、総人口比は立川が上回ります。

### 4. 在留資格は「留学」と「永住者」が拮抗

八王子市議会資料の2025年4月時点の在留資格構成は、留学26％、永住者25.6％、技術・人文知識・国際業務9％です。これは住民基本台帳の2026年10月とは時点も資料も異なるため混ぜません。「留学」には日本語教育機関の学生も含み得るほか、第5弾で見た市内大学・短大・高専で学ぶ人とは集計対象と時点が異なります。

## 結び

外国人住民が増え、その内訳も変わりました。市は多言語の案内や相談窓口を設けています。住民同士がどのように交流しているか、案内や窓口が暮らしにどう役立っているかを知るには、人口統計に加えて別の調査が必要です。
