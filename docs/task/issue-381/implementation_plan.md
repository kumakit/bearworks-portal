第一弾・第二弾の「問い → 図 → 読み取り → 統計の学習」を第三弾にも通す。
1. 日最高・日最低の指標を分け、4地点比較を同一軸で表示。

5. 36年を観測環境の比較可能な区間に分割。原因の一般論と直接検証を区別。
6. 数値例を伴う確認問題、出典・品質・限界を整備。
