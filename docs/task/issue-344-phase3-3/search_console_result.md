`sampling-bias` は公開HTTP 200で、動的routeがcanonicalを生成し、公開サイトマップにも含まれる。一方、URL検査はGoogle未認識、未クロール、参照元サイトマップ未検出だった。インデックス登録レポートの最終更新日2026-08-21に対し、サイトマップの最終読み込みは2026-08-23であり、表示時差を含む可能性を残す。現時点では取得失敗、robotsブロック、noindex、canonical不一致を確認していないため、コードを変更せず次回の読み取り専用監視対象とする。
