## 分析方法とデータ成立条件

1. 原本の取得日時・URL・SHA256・仕様版・基準日・変換コード版をmanifestに残す。ZIP内を直接読み、年別に正規化して固定入力を作る。原本hashは調査JSONに保存済み。原本の一時取得先は `C:/Users/kumat/AppData/Local/Temp/issue413-L01-{26,16}_13.zip`。実装時に採用版をgit管理外の作業用領域へ保全する。
2. 各市・年の全住宅地について単純平均・中央値・最小/最大・分位点・件数と分布を生成。中央値は偶数件なら中央2値の平均。欠損を0にしない。極端値は原典を確認し、自動除外しない。平均価格は面積加重ではない。
3. 東京都等の公表表と件数・平均を照合し、丸め単位を記録。差が丸めで説明できなければ記事の確定を止め、用途・標本・欠損を再調査。平均変動率は継続地点の各変動率の平均とし、平均価格の前年比とは分ける。
4. 各年の分布比較はその年の全標準地を用い、「標本構成も変わる2時点比較」と明記。2026年に残る地点の過去価格だけで2016年全体を代表させない。
5. 同地点比較は公式の価格/属性履歴・選定フラグ、2016原典の価格/所在地/面積/座標等を照合。年途中の選定替や用途変更を除外するため、2017～2026年の履歴定義と継続状態を確認する。番号一致・近接座標・住所一致単独で確定しない。測地系差（2016 JGD2000 / 2026 JGD2011）を距離変化と誤認しない。
6. 継続の根拠が確保できない地点は理由付き除外。同地点系列を成立させられなければ、その系列を省略し、両年全標本の分布比較に限定して限界を明示する。この代替はIssueの許容範囲内。
7. 駅距離は公式の道路距離の定義・欠損コードを確認できた場合だけ補助散布図にする。主3比較の完成を優先し、因果や購入推奨は述べない。100㎡試算を出すなら地価×100の仮計算と費用除外を明記する。

## 地図・記事の構成

6市のドット分布と表 → 八王子の地点地図 → 平均と市内幅 → 過去比較 → 地価だけでは判断できないこと → 方法・出典・再現手順、を基本とする。検算後に発見を冒頭へ置く。

地図は国土地理院淡色タイルを表示時に読み、固定341地点のうち八王子124地点をポイント表示する。価格帯の色に加えて凡例の数値・選択枠・地点表・地点selectを提供。タップ/クリック/キーボードで標準地番号、所在地、円/㎡、2026-01-01を確認できるようにする。町丁面塗り・境界精度の主張・売地表示は行わない。タイル座標への投影と実地点の対応を既知点で検証する。

地図は記事専用の遅延読込部品に限定。初回HTMLには主要結論と全地点表を含める。タイル取得失敗時も地点表と座標上の点を確認できる。地図ライブラリの新規追加は必要性を確認して最小限とする。ズーム/移動や選択の実装で記事の読書を妨げない。
