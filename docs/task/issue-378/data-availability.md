最新追記（2026-09-15）：本取得・被覆/品質/均質区間の検査を完了。主解析35冬候補のうち2014/15を除いた34冬・2区間でH1を評価し、4事例・2025年1〜2月の温湿度探索も実装した。[確定した結果と制約](../../history/20260915_issue-378_snow-article.md)を参照。以下は2026-09-13の公式HTML抜き取り調査時点の記録。

## 調査結果と実装への判断

長期の主分析は、同時刻の気温・降水量を使うH1とする。八王子の湿度は確認した境界の2024年12月23日17時から数値が現れ、1990〜2025年の長期温湿度比較はできない。2025年末までを対象にすると、湿度が揃う完全な12〜2月の冬はない。2025年1〜2月は部分季節の探索として扱えるが、長期の雪頻度を説明する標本にはしない。

これは抜き取った表の数値出現境界であり、公式な観測開始日時や、それ以前の全履歴を確定したものではない。2026年2月まで延ばす案は完全冬1季を得る追加案で、今回の取得・分析にはまだ含めていない。

八王子の降雪・積雪・天気を東京都心や隣接地点から補完しない。気温差を降雪量差へ読み替えない。画像による導入と、観測事実による仮説評価を分離する。

## 境界と天気の具体的な確認

- 八王子2024年月別: 1〜11月の湿度は `///`、12月は品質記号付き数値。
- 八王子2024年12月日別: 22日は欠け、23日の湿度に数値と `]`、24日以降数値。
- 八王子2024-12-23時別: 17時に湿度44%、気温7.2℃。降水量は `0.0 ]`。17時より前には湿度数値なし。欠けた時間を0%として扱わない。
- 東京都心2024-02-05時別: 天気が埋まるのは3・6・9・12・15・18・21時。12時は雨、15・18・21時は雪。他時刻への前方補完は禁止し、降水量だけから「都心は雨」と判定しない。
- 東京の天気観測方式を他地点の自動化と混同しない。2024年3月の自動化資料では東京・大阪の目視観測継続が明記される。

## 本取得の形式・品質規則

本分析は[気象庁のCSVダウンロード](https://www.data.jma.go.jp/risk/obsdl/)を優先する。[操作説明](https://www.data.jma.go.jp/risk/obsdl/top/help1)では取得量の目安100以下が必要。地点・期間・項目を分割する場合は重複期間を持たせる。

[CSV仕様](https://www.data.jma.go.jp/risk/obsdl/top/help3)に従い、値だけでなく品質・現象なし・均質番号を保持する。

- 品質8は正常、5は準正常、4は資料不足、2は疑わしい、1は欠測、0は非観測・統計項目なし。採用範囲は分析設計で固定する。
- 現象なしと数値0を区別する。HTMLの `///` だけから非観測・欠測の原因を一律に決めない。原記号を残し、CSV品質と項目メタデータを照合する。
- 日界24時は翌日0時へ正規化し、元表記も保持する。JSTで重複・抜けを検査する。
- 均質番号は取得ごとに振り直されるため、別CSVで同じ番号でも同じ区間とみなさない。重複期間と地点履歴で対応を確認する。
- 天気コードの雨・みぞれ・雪等を原値で保持する。欠測時刻を埋めず、解析対象の天気分類は設計で明記する。

推計気象分布は約1kmの推計で直接観測とは異なる。公開画面の過去48時間だけでは長期検証の入力にならず、歴史アーカイブの入手方法・方式変更は未確認。本分析への採用は保留する。

## 保存した証拠と再現方法

`evidence/` に17件の公式HTMLと対応JSONを保存。JSONは元URL、取得時刻、HTMLのSHA-256、読み取り用行配列を含む。取得対象は `jma-probes-monthly.json`、`jma-probes-boundary.json`、`jma-probes-final.json`。`probe-jma-availability.ps1 -RequestFile <対象JSON>` で未取得分だけを取得する。

これは可用性調査のsnapshotであり、解析用raw datasetやpublication bundleではない。行配列は結合セルを完全な表構造へ復元していないため、列定義は原HTMLに照合する。本分析へそのまま投入しない。
