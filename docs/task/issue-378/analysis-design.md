# Issue #378 分析設計 r1

固定日: 2026-09-13 / CSV入力契約確認: 2026-09-14。仮説の集計前に固定する規則。可用性境界の抜き取り値は確認済みだが、以下の主分析結果は未算出。

## 対象と分母

- 必須地点は八王子44112と東京44132（読者向け「東京都心」）。府中・青梅は初版の主分析に含めない。
- 長期気温比較の対象候補を1990年12月〜2025年2月の35完結冬とする。各冬は12月1日1時〜3月1日0時JST（観測日の12〜2月、各日1〜24時）。期間外の1〜2月1990年と12月2025年を混ぜない。
- 全期間を一つの均質な母集団としてプールしない。CSVで両地点・必要要素の均質境界を照合し、共通区間ごとに結果を分ける。境界をまたぐ冬の集約は参考値にも使わず除外数を記録する。
- 温湿度比較は2025年1月1日1時〜3月1日0時JSTを部分季節の探索として固定。期間延長を結果に応じて行わない。
- 気温は正時値、降水はその正時までの前1時間量。実際の降水瞬間の気温という表現は避ける。

## 入力と品質

公式CSV、全数値、品質と均質番号付き、日付リテラル、全時間を使用する。試験用の境界見本は2024年12月22〜24日・両地点・気温／降水／湿度／天気／降雪／積雪。取得済みHTMLの列構造をCSV仕様とみなさない。

各値に地点・要素・日時JST・元日時・元値・品質・現象なし情報・snapshot・均質番号を保持する。品質0/1/2/4/5/8以外は停止。主分析は8のみ、感度分析は8と5。4を採用せず、0・1・2を数値0に変換しない。非有限値・湿度範囲外・負降水量は停止。天気はカテゴリであり平均しない。

同一地点・要素・日時の重複は停止。CSVの取得範囲の期待行は欠測値の行を含め全て必要で、行欠落と品質付き欠測を区別する。疎な天気欄を補完せず、品質0をそのまま保持する。現象なしの降水は原フラグを残し、量の比較では品質が有効な場合のみ0として扱う。

snapshotを結合する場合、同じ均質番号でも同一区間と推定しない。重複した1日以上の値・品質・メタデータで対応を照合し、曖昧なら結合を停止する。比較区間の識別には両地点の気温・降水の均質性を含める。

## H1と降水イベント

1. 両地点の気温・降水が全て有効な同時刻を比較可能ペアとする。
2. 片方以上の降水量が0.5mm以上なら降水時、両方が0.5mm未満なら非降水時。どちらかの降水が無効なら判定不明。気温欠測による除外も別計数する。
3. `ΔT = 八王子 − 東京都心`。負なら八王子が低温、0は同温。低温割合の分母には同温を含む。
4. 有効な非降水が6時間連続したら別イベントとする。欠測・非観測・行欠落・均質境界をまたいで連結しない。欠測や期間端で切れたイベントは不完全とし、主イベント集計から除外。12時間分離と両地点とも降水の条件を感度分析に使う。
5. イベントの降水時が3時間以上、気温ペア有効率が90%以上のものだけ平均差を計算。これは今回の解析規則であり、気象庁のイベント定義ではない。
6. 冬ごとに気温・降水4要素の有効ペア率95%以上を必要とする。90%の場合も感度確認する。満たさない冬を除外し、欠測数と分母を必ず表示する。

実装前の明確化（2026-09-14、Luna点検反映）: 上記4の「欠測」はイベント分離に使う降水の欠測を指す。気温欠測は降水イベントを切らず、上記5の気温ペア有効率で扱う。降水未知・均質境界後は、新たに6時間の既知非降水を確認するまで左端不完全とする。期間先頭も同様。イベント末尾の区切り用6時間は降水時間数に含めない。これにより10降水時間の気温9ペアは採用、8ペアは除外となる。

主図は降水時ペア差の箱ひげ図、展開ヒストグラム、イベント平均差の点列、事例時系列。時刻を独立標本としてt検定しない。イベントも自動的に独立とは仮定しない。

H1の記述的な「多い」は、共通均質区間内で有効な冬5季以上かつ完全イベント30件以上、降水時の低温割合60%以上、イベント平均差が負の割合60%以上、両方の基準を満たすこととする。達しない場合はこの事前基準では不支持、必要件数未満は資料不足。これは観測集合内の記述判定であり、将来や市域全体への有意差の主張ではない。品質・イベント分離・降水条件の感度で判定が変われば本文で結論の不安定さを明示する。

## H2〜H4と事例

- H2: 東京の天気コード10（雨）が有効に記録された正時のみを「都心は雨」の対象とする。11（みぞれ）・12（雪）は別カテゴリ。天気のない時刻を前方補完しない。八王子の温湿度散布図は探索図とし、雨雪の判別式をまだ持たないのでH2の雪条件頻度は直接検証不能とする。湿球温度の適用式を追加する場合は独立した設計改訂と一次資料確認が必要。
- H3: 2014年2月7〜9日、同14〜16日、2018年1月22〜23日、2024年2月5〜6日を公的資料で確認する事例候補に固定。これらは有名な降雪事例を選んだケーススタディで、全南岸低気圧の代表標本ではない。「平常時より明瞭」の一般判定は、独立した非降雪を含む低気圧カタログがない段階では資料不足。直前の晴天を比較群にして降水条件差を混同しない。
- H4: 同じ事例の自治体等の積雪・交通影響記録を別の証拠として確認する。駅前映像と気象観測点を同一視しない。八王子の実測降雪開始がない場合、低温開始時刻を「雪が早い」へ読み替えず直接検証不能とする。

## 統計検定2級との対応

実データで記述統計、対応のある差、相関・回帰、条件付き割合の定義を見せる。箱ひげは線形補間四分位、ひげは1.5IQR内の最遠観測、外は外れ点。ヒストグラムは1℃幅で両端を明記する。

相関・回帰は同時刻ペアの記述量として示し、季節・時刻・気圧配置の共通要因を注記する。p値は初版の主判定に使わない。CIは独立性・標本単位の検討を終えるまで実測の推測統計として表示しない。CIの式・SDとSEの違いは明示した架空教材で学べるようにし、観測結果と分離する。
