# Issue #378 ミニ設問案 r2

2026-09-13。Gemini案をCodexが訂正した教材設計。以下の数値・観測状況は全て学習用の仮想例で、八王子の分析結果ではない。実装時も各設問にこの表示を付ける。

## 1. 平均と中央値だけで分かること（セクション4）

問い: 仮想的な気温データで平均値が中央値より低いことだけが分かっています。この情報から言えることはどれですか。

1. 極端な低温の外れ値が必ず存在する。
2. 分布は必ず低温側に長い裾を持つ。
3. 平均値と中央値だけでは、外れ値の有無や分布全体の形は断定できない。
4. データは必ず正規分布に従う。

正答: 3。平均と中央値は異なる要約であり、その大小関係だけで外れ値や歪度を特定できない。分布図や実際の値も確認する。誤答の原因は、典型的な分布で見られる傾向を必ず成り立つ規則と取り違えること。

## 2. 95%信頼区間（セクション5）

問い: 前提を満たす方法で求めた母平均差（八王子−東京都心）の95%信頼区間が [-2.1, -1.5]℃でした。正しい解釈はどれですか。

1. 今後のイベントの95%がこの範囲に入る。
2. 固定された母平均差がこの区間に入る確率は95%である。
3. 母平均差が0である確率が5%以下である。
4. 同じ標本抽出・区間推定手順を繰り返すと、得られる区間の約95%が母平均差を含む。

正答: 4。信頼水準は繰り返しにおける区間の被覆率を表す。個別イベントの分布や、固定した区間に対する母数の確率とは区別する。誤答の原因はSD・SE・予測区間を混同すること。

## 3. 対応する差の系列相関（セクション5）

問い: 同時刻の2地点の差を1000時間分作ったところ、差の系列に強い正の自己相関が認められました。通常の対応t検定にそのまま入れる問題点はどれですか。

1. 標本数1000以上ではt分布を使えない。
2. 差を独立な1000観測として数える前提が満たされていない。
3. 対応するデータには原理的に差の検定を使えない。
4. 降水量が違う地点の気温平均は計算できない。

正答: 2。対応t検定は差についての1標本t検定に相当し、ペア間の差の独立性等が重要。正の系列相関を無視すると平均差のSEを過小評価し、有意になりやすくなる場合がある。イベント集約だけで独立性が保証されるわけではない。誤答の原因は行数を独立な情報量と同一視すること。

## 4. 強い相関と因果（セクション6）

問い: 仮想的な2地点の気温の相関が r=0.92 でした。適切な解釈はどれですか。

1. 東京都心の気温が八王子の気温を直接上昇させている。
2. 観測した組には強い正の直線的関連があるが、共通要因の影響や直接の因果は相関だけでは判別できない。
3. 2地点間に平均気温差はない。
4. 気温を誤差ゼロで予測できる。

正答: 2。共通の気象条件や時間帯が関連に寄与する可能性があるが、今回の相関だけで原因を特定できない。高相関でも地点間に一定の差はあり得る。誤答の原因は連動性を同値性や因果と混同すること。

## 5. 条件付き割合の分母（セクション7）

学習用の仮想表。Aは単なる練習用の二値指標で、降雪や温湿度による雪判定を表さない。表の対象は都心の雨/雪の分類とAが両方判定できた160時間、未判定時間はこの教材では0とする。

| | A成立 | A不成立 | 合計 |
|---|---:|---:|---:|
| 都心：雨 | 30 | 120 | 150 |
| 都心：雪 | 10 | 0 | 10 |
| 合計 | 40 | 120 | 160 |

問い: 都心が雨だった時間のうち、A成立の割合を求める式はどれですか。

1. 30/160
2. 30/40
3. 30/150
4. 40/150

正答: 3（20%）。条件となる雨の行だけを分母にする。これは仮想表内の記述割合であり、将来の降雪確率や独立性検定の結果ではない。誤答の原因は全体割合や逆向きの条件付き割合を使ってしまうこと。
