# 八王子はまだ学生の街？

## 導入

JR八王子駅周辺を扱った[前回の記事](https://bearworks.uk/labs/hachioji-city-center)では、居住人口の増加と通りごとの人流の違いを市のデータから確かめました。もう一つ、八王子を語るうえで欠かせないのが「学園都市」「学生の街」という顔です。では、いま八王子は数字のうえでもまだ学生の街と言えるのでしょうか。八王子市の公表資料と中央大学の公式発表をもとに、確認できる範囲の数値をたどり、言えることと確かめられないことを整理します。

## 数値で分かったこと

### キャンパス学生数は長期でも前年比でも減少

八王子市「第2期はちおうじ学園都市ビジョン」19ページの「市内の大学等」の系列は、2006年に104,130人、2022年に94,823人、2023年に89,763人でした。2006年から2023年に14,367人（約13.8％）減少し、そのうち2022年から2023年の減少は5,060人（約5.3％）でした。

このグラフが数えているのは、キャンパスで学ぶ学生です。2023年4月には、中央大学の法学部全学年と大学院法学研究科が多摩から文京区の茗荷谷へ移転しました。移転の時期は学生数が減った年と重なります。市のグラフは複数校の合計なので、移転が減少にどれだけ影響したかを知るには大学別の内訳が必要です。

### 市内21校とコンソーシアム加盟25校

同じ19ページでは、2023年度に市内21校で約9万人、大学コンソーシアム八王子の加盟25校で約10万人が学んでいると説明されています。加盟25校の集計には市内21校が含まれます。市が掲載する2025年5月1日時点の加盟校一覧にも、町田市や多摩市などに所在する学校が載っています。

### 学ぶ場所と住む場所の距離――Web調査から

八王子市の大学生Web調査では、回答者682人のうち、八王子市内在住と答えた人が32.1％、卒業後に市内に住みたい、または住む予定と答えた人が9.7％でした。調査は2023年5月1日から6月30日に行われ、メールと市広報SNSで回答を募りました。この割合は回答者についての結果です。学生全体の居住割合を推計するには代表性の確認が、卒業後の転居を知るには追跡調査が必要です。

### 確かめられないこと

2024年以降に定義が揃う年次値は現時点で未確認です。そのため、いまの最新値や他都市との順位、未確認の移転規模は示せません。

## 図表案2点

1. **市内の大学等で学ぶ学生数の推移（2006～2023年）**。市の原図と照合済みの18年分を折れ線にする。2006年、2022年、2023年の人数と、中央大学の移転時期を注記する。
2. **学校の集計範囲と学生Web調査**。2023年度の市内21校がコンソーシアム加盟25校に含まれることを図解する。Web調査の市内在住32.1％と卒業後に市内に住みたい、または住む予定9.7％を、回答者682人を分母とした横棒図で示す。

## 短い結び

2023年度の八王子では、2006年より学生数が減ったあとも、市内21校で約9万人が学んでいました。学生がどこで学び、どこで暮らすかを見ていくと、「学生の街」の姿が少し具体的になります。
