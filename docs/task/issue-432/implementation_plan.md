# 八王子を数字で読み解く 第5弾の実装計画

第5弾「八王子はまだ学生の街？」を `/labs/hachioji-students` に追加する。市の資料からキャンパスの学生数がどう変化したかを確かめ、在籍者数、学校数、学生アンケートの回答者を区別して説明する。第4弾から新記事へ案内する。

## データと記事の根拠

- 八王子市の「第2期はちおうじ学園都市ビジョン」19ページの図で、「市内の大学等」は2006～2023年の18点、コンソーシアム加盟大学等は2009～2023年の15点を確認した。市内系列は2006年から2023年に14,367人（約13.8％）減、2022年から2023年に5,060人（約5.3％）減。加盟校の系列は加盟範囲の変更が比較に与える影響を確認してから掲載を判断する。 [市の確定版 第2章](https://www.city.hachioji.tokyo.jp/kurashi/shimin/002/a791636/005/p033733_d/fil/vision2_P8-25.pdf)
- 市の資料は2023年度について、市内21校で約9万人、コンソーシアム加盟25校で約10万人と説明している。市の一覧には2025年5月1日現在の加盟25校が掲載され、市外所在校と市境をまたぐキャンパスを含む。記事の図表は集計年と対象を明記する。 [市の学校・加盟校一覧](https://www.city.hachioji.tokyo.jp/kurashi/shimin/002/a791636/001/p031711.html)
- 2023年5～6月にメールと市広報SNSで案内した大学生Web調査の682回答では、市内居住32.1％、卒業後に市内に住みたいか住む予定9.7％。質問文と回答者数を示す。調査回答から全学生の居住割合や卒業後の実際の行動を推計するには、代表性や追跡調査の情報が必要になる。 [市のアンケート集計結果（1、25、31ページ）](https://www.city.hachioji.tokyo.jp/kurashi/shimin/002/a791636/005/p033733_d/fil/questionnairesummary.pdf)
- 拓殖大学の2015年の再編、杏林大学の2016年の移転、中央大学法学部の2023年の移転を大学の一次資料と照合し、学生数の図に出来事を添える。時系列の前後関係を示し、移転ごとの寄与の定量化には大学別の比較可能な在籍者数が必要と説明する。 [拓殖大学](https://www.takushoku-u.ac.jp/summary/renaissance/)・[杏林大学](https://www.kyorin-u.ac.jp/cn/html/kyorin/00003/201602261/index.html)・[中央大学](https://www.chuo-u.ac.jp/aboutus/history/history_01/)
- 市の「八王子市の概要」に2024年5月1日現在の21校・90,768人と、2025年5月1日現在の21校・91,540人がある。学校・キャンパスの範囲や大学院の扱いがビジョンの系列と一致すると確認できないため、別資料の参考値として掲載する。他都市比較にも同じ判断基準を適用する。 [2024年度版](https://www.city.hachioji.tokyo.jp/contents/kouhou/005/001/p025751_d/fil/r6gaiyou_syusei.pdf)・[2025年度版](https://www.city.hachioji.tokyo.jp/contents/kouhou/005/001/p025751_d/fil/r7gaiyou.pdf)
- 元資料の図版や写真に代えて、公表数値から図表を作成し、出典と再集計の有無を表示する。公開前に元資料と集計値の利用条件を確認する。 [八王子市サイトの著作権案内](https://www.city.hachioji.tokyo.jp/987/p012154.html)

## 制作と検証

1. 検算済みの値、対象、年度、出典ページ、取得日を固定入力に保存し、記事とグラフが同じ集計を参照できるようにする。外部取得を必要としない再現手順を用意する。
2. 日本語の初稿は、公開資料のみにアクセスできる作業フォルダで Antigravity に依頼する。Google AI Pro の基本枠を使い、セッション内の追加クレジットを無効にする。Codexが本文の数値と表現を原本に照合する。
3. 前作と同じ紺色のヘッダー、3:2の画像、青緑と琥珀色の要点カードを使用し、架空の大学キャンパスを描いた新しいイラストを配置する。PCは本文と画像を左右、スマホは上下に並べる。`app/site-content.ts` で Labs 一覧・sitemap に登録し、前作との相互リンク、canonical、OGP、公開済みの第6弾がある場合の導線を確認する。
4. 年度と単位、数値・割合、欠損、対象区分、リンク、モバイル表示を検証する。既存の lint・ビルド・Workers CI と関連ページの回帰確認を行う。
5. push、mainへのマージ、本番公開はそれぞれ承認範囲を確認する。公開前後の検証と復旧は [デプロイ手順](../../operations/deployment.md) に従う。
