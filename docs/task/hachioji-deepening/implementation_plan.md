# 第5弾・第6弾 深掘り改訂 実装計画

対象は `/labs/hachioji-students`（第5弾）と `/labs/hachioji-international`（第6弾）です。公開済みの2記事に、統計的な分析と見やすいグラフを加えます。分析結果は、一般の人にもわかる解説にします。解説文の作成は Antigravity（Gemini）に依頼し、Codex が数値と表現を検算・確認します。

> [!NOTE]
> この文書は計画までです。実装・push・PR・本番公開は、承認を得てから着手します。本番公開は `AGENTS.md` の承認ゲートに従います。

## 1. 現状の課題

| 項目 | 第5弾 | 第6弾 |
|---|---|---|
| 現在の分析 | 学生数の折れ線1本、アンケート2値の棒 | 人数・割合の推移、国籍・地域の構成、近隣6市の比較、在留資格 |
| 不足していること | 「減少が大きいのか、普通の変動なのか」の判断材料。アンケートの数字がどこまで信用できるかの説明 | 「増加の中身」の説明（日本人人口の減少との関係、国籍別の寄与）。増え方の速さの比較 |
| グラフの作り | 手書きSVG（色・凡例・ツールチップが最小限） | 同左 |

## 2. 追加する分析

方針は3つです。(a) 公表データから再計算できる指標だけを使う、(b) 因果関係や将来予測を断定しない、(c) 各分析に「読み方」の短い説明を付ける。

### 第5弾「八王子はまだ学生の街？」

| # | 分析 | 具体的な指標 | 一般向けの説明 |
|---|---|---|---|
| S1 | 指数化 | 2006年＝100 とした推移。2023年は約86.2。年平均変化率は約 −0.9％（スクリプトで確定） | 「17年間でおよそ7人に1人分が減った」など、量感で伝える |
| S2 | 前年比の棒グラフ | 各年の増減数と増減率。キャンパス移転年（2015、2016、2023）を強調 | 移転年の減り方が、ふだんの年の増減の幅（四分位範囲）と比べて大きいかを示す。同時期に起きたことは示すが、「移転が原因」とは断定しない |
| S3 | 区間別の傾き | 2006～2014年と2015～2023年の年あたり増減（単純な線形回帰） | 減少のペースが途中で変わったかを平易に説明。回帰直線は説明用で、将来の予測には使わない |
| S4 | アンケートの誤差幅 | 市内在住 32.1％（682人中約219人）、卒業後の居住意向 9.7％（約66人）に Wilson 95％信頼区間（約 ±3.5ポイント、±2.2ポイント。確定は検算で行う）を付ける | 「32％という数字には、おおよそ3ポイント程度のぶれがある」と説明。Web回答で無作為抽出か不明なため、学生全体に拡大して言わないと明記 |
| S5 | 人口あたり学生数（条件付き） | 市の総人口と基準日・定義が揃う年だけ、人口100人あたりの学生数を計算 | 揃わなければ掲載しない。定義が違うものを混ぜない |
| S6 | 参考値の扱い | 2024年・2025年は基準日付きの別マーカーとして表示し、折れ線とは結ばない | 現行方針を維持 |

### 第6弾「八王子は国際的になってきている？」

| # | 分析 | 具体的な指標 | 一般向けの説明 |
|---|---|---|---|
| I1 | 人口変化の内訳 | 2013→2026年で総人口は −4,575人。内訳は外国人 +10,964人、日本人 −15,539人（内訳の整合はスクリプトで検算） | 「市の人口はほぼ横ばい。中身は、日本人が減り外国人が増えた」と見せる。積み上げ棒やウォーターフォールで表示 |
| I2 | 指数化と年平均成長率 | 外国人住民は2013年の約2.2倍、年平均約 +6.3％。日本人・総人口は同じく2013年＝100の線 | 「何倍になったか」と「毎年何％増えたか」を並べる |
| I3 | 前年差と停滞期 | 年ごとの増加人数の棒グラフ。2020～2022年前後の伸びの鈍りを確認（範囲は実データで確定） | 出入国の制限など外部要因が考えられるが、データだけでは原因を断定しないと明記 |
| I4 | 国籍・地域別の寄与 | 5区分と「その他」について、2013→2026年の増加人数と倍率の横棒グラフ。構成比の100％積み上げ面グラフ | どの国籍・地域が増加をけん引したかを示す。国籍から個人の属性は推測しない |
| I5 | 近隣6市の比較 | 人数×外国人割合の散布図、または割合のドットプロット。6市の中央値を基準線として表示 | 順位や優劣を一般化しない。6市の同日比較に限定 |
| I6 | 在留資格 | 別図として維持。基準日と丸めを明示 | 現行方針を維持。他の統計と換算しない |

> [!IMPORTANT]
> 次の表現は使いません。「移転が学生減少の原因」「外国人増加が地域の国際化の進展を示す」「今後〇年で〇人になる」。回帰・指数・信頼区間は「過去のデータの整理」として説明します。

### 2.1 地図の追加（調査A・Bの結果に基づく）

調査結果は [research-A](research-A-foreign-residents-by-area.md) と [research-B](research-B-boundaries-and-sources.md) にあります。地図は次の2点だけを対象にし、それ以外は対象外とします。

| # | 記事 | 地図 | データ | 判定 |
|---|---|---|---|---|
| M1 | 第6弾 | 町丁別の外国人住民の変化（2024年4月末→2026年10月末）。主指標は人口に占める割合（ポイント差）、補助に人数の増減 | 八王子市の町丁別CSV（CC BY 4.0、外国人人口の男・女・その他を合計）。境界は e-Stat の国勢調査「町丁・字等境界データ」（2020年） | 条件付きで可 |
| M2 | 第5弾 | 大学・キャンパスの位置図と、移転3件（拓殖大 2015年、杏林大 2016年、中央大 2023年）の元・移転先 | 市の学校一覧の所在地と大学の公式サイト | 可 |

**対象外**: 地域別（学校別・町丁別）の学生数の変化（公開資料なし）、国籍別の地図（町丁別の国籍別表なし）。

M1 の条件と作り方:
- **比較期間は2時点に固定**します。2024年4月と2026年10月は、大字コードと大字名称が199行ずつ一致することを確認済みです。長期の変化は国勢調査（2000～2020年の5時点）で別図にし、住民基本台帳とは混ぜません。
- **結合の検証**: 市の5桁「大字コード」と境界データの町丁コードの公式対応表は未確認です。名称を正規化して照合し、一致・不一致・多対一を一覧にして、未結合の町丁が残らないか確認します。市全体の合計と地図の合計が一致することも検算します。
- **町区域の変更**: 2016年3月（インター北）や2024年8月（上野第二地区）などの変更地区は、前後で同じ範囲に合算できる場合のみ比較し、できない町丁は「比較できない」と表示します。
- **少人数の扱い**: 外国人人口が少ない町丁は、正確な人数や差を出さず「少数」の区分で表示します。閾値は、分布を見て実装時に決めます（表示基準は注記に明記）。
- **見え方**: 人数ではなく割合を主にし、面積の大きい町丁が目立たないようにします。ツールチップのかわりに、上位・下位10町丁の表（数値表）を併設します。スマホでは地図を縦に長く表示し、凡例を地図の下に置きます。
- **出典表記**: 「八王子市『町丁別世帯数及び人口』（CC BY 4.0）、政府統計の総合窓口（e-Stat）『令和2年国勢調査 町丁・字等境界データ』を加工して作成」と、加工した旨を併記します。別途使う背景地図は、提供元の条件を確認してから使います。境界は調査用で、行政の正式な境界ではないと注記します。
- **技術**: 境界の Shapefile を GeoJSON に変換して簡略化し、`public/data/hachioji-international/` に固定します。描画は、地図ライブラリを追加せず、SVG（d3-geo などの小型ライブラリは実装時に比較して決める）で行います。背景地図のタイルは使いません。

M2 の条件と作り方:
- 市の一覧の住所と大学公式のアクセス情報を照合し、緯度・経度を付けます。座標は目視で確認します。
- 移転前後の日付とキャンパス名を各ピンに付けます。市外の所在校や市境をまたぐ学校は、そのように注記します。
- 位置図は学生数の増減を示す図ではないことを、図の説明に書きます。

## 3. グラフの方針

- **ライブラリ**: リポジトリに導入済みの Recharts 3.8 を使い、`"use client"` の小さなコンポーネントに分離します（`components/hachioji/` など）。既存の手書きSVGは、同等以上の品質を確認してから置き換えます。置き換えで品質が落ちる図は手書きのまま残します。
- **見やすさ**: 色覚に配慮した配色、第4～6弾と同じ紺・ティール・琥珀の配色を踏襲します。凡例は直接ラベルにします。軸・単位・基準日・出典を図の下に必ず表示します。
- **スマホ**: 幅 360px で文字の最小サイズ・ラベルの重なりを確認します。ツールチップは、タップで値を読めるようにします。
- **アクセシビリティ**: 図ごとに `role="img"` と要約、開閉式の数値表を付けます（現行を踏襲）。
- **性能**: 追加後に `next build` でページごとのJSサイズを確認します。大きく増える場合は、図だけを遅延読み込みにします。

## 4. データと検算

0. 地図用に `scripts/build-hachioji-area-map-data.mjs`（M1 の取得・結合・検算・GeoJSON 生成）と、M2 の座標データを追加します。結合の対応表と未結合の一覧は、検証用ファイルとして保存します。
1. `scripts/analyze-hachioji-students.mjs` と `scripts/analyze-hachioji-international.mjs` を新設します。既存の固定データ（`public/data/hachioji-students/student-data.json`、`public/data/hachioji-international/population.json`）だけから、指数・増減・年平均変化率・傾き・信頼区間・寄与を計算し、`analysis.json` に出力します。
2. 既存の検算スクリプト `validate-hachioji-*-data.mjs` に、分析値の再計算チェックを追加します。人口の内訳の整合、丸め、基準日の一致を確認します。
3. 一般向けの文章が参照する数値は、すべて `analysis.json` から取り出します。文章にだけ存在する数値は作りません。
4. 新たな外部データの取得は原則しません。S5 で市の総人口が必要な場合は、既存の `hachioji-population` データと基準日を照合し、揃わなければ見送ります。

## 5. 文章作成（Antigravity / Gemini）

1. Orca の `/orchestration` から Antigravity のワーカーを2本（第5弾・第6弾）起動します。前回と同じく Google AI Pro の基本枠で、そのセッションでは追加AIクレジットを無効にします（既存プランの枠内・追加課金なし）。
2. ワーカーに渡すのは次のものだけです。
   - `analysis.json`（検算済みの指標）と図の一覧
   - 既存記事の文体・見出し構成
   - 禁止表現リスト（上の IMPORTANT）と、断定を避ける言い回しの例
   - 文字数の目安（各分析の解説は200～350字。専門用語には1文の言い換えを付ける）
3. 依頼内容は「各グラフの読み方」「分析の結果」「なぜそう言えるか、言えないこと」「まとめ」の4要素です。中学生でも読める文章にします。
4. 受領後、Codex が数値・単位・基準日・出典・断定表現を照合し、必要な修正を行います。
