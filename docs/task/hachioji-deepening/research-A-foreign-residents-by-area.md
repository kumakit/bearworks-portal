# 調査A 八王子市の町丁・地区別の外国人人口

調査日 2026年11月28日  
対象記事「八王子は国際的になってきている？」（`/labs/hachioji-international`）

## 判定

**条件付きで示せる。** 八王子市の住民基本台帳の町丁別CSVに外国人人口の内訳があり、市内の町丁別の増減を比較できる。2024年4月末と2026年10月末のCSVは、大字コードと大字名称の組が両方とも199行で一致する。たとえば横山町（`00100`）は、外国人人口の男・女・その他を合計すると228人から249人になった。地図では比較する両時点の区域が同じか確認する。コードと名称の一致は確認済みで、境界形状の照合は未確認。 [2024年4月CSV](https://www.city.hachioji.tokyo.jp/tantoumadoguchi/002/003/matisetaicsv_d/fil/chouchoubetsu_jinkou_0604.csv)・[2026年10月CSV](https://www.city.hachioji.tokyo.jp/tantoumadoguchi/002/003/matisetaicsv_d/fil/chouchoubetsu_jinkou_0810.csv)

国勢調査でも**2000・2005・2010・2015・2020年の5時点**で、市区町村コード `13201` の町丁・字等別の外国人人口を取得できる。長期比較では、同じ区域の公表値を比較する。住民基本台帳と国勢調査は集計対象と基準日が異なるため、記事では出典と期間を明記する。 [国勢調査の調査対象](https://www.stat.go.jp/data/kokusei/2020/gaiyou.html)・[八王子市の住民基本台帳制度](https://www.city.hachioji.tokyo.jp/kurashi/kosekijumin/007/p004496.html)

国籍・地域ごとの人数は市全体で確認できた。町丁・字等、学区、行政区域、支所管内を単位とする国籍・地域別人口、および学区等を単位とする外国人人口総数の公表表は、確認した公開資料の範囲では未確認。 [八王子市の人口関連オープンデータ](https://www.city.hachioji.tokyo.jp/contents/open/002/p005866.html)・[八王子市の外国人に関するデータ](https://www.city.hachioji.tokyo.jp/kurashi/shimin/004/gaikokujinndata/index.html)・[東京都の外国人人口](https://www.toukei.metro.tokyo.lg.jp/gaikoku/2026/ga26010000.htm)・[国勢調査の国籍別人口](https://www.e-stat.go.jp/dbview?sid=0003445244)
