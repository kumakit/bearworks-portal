## レビュー時に添付する証跡

- Phase 0 の `settings` と小規模照会から作った、データセット×期間の可否表。24 時間は `httpRequests1hGroups` の同じ応答で時間別値と `countryMap` を得て、今回の 24 行で各時間の国別和が合計と一致した。7/30 日の Adaptive はサンプリングを含む。秘密値、zone ID、認証主体の識別子、原文エラー、個人アクセス情報は除く。
- 新旧契約のブロック・版・取得状態・Digest 必須監視対象の対応表。
- Natural Earth v5.1.1 のパブリックドメイン利用条件、未確定の実コード対応・未知国の扱いと、公開する日本語説明の案。

## 確認してほしい点

1. 取得可能範囲・粒度・サンプリング・母数から、24 時間グラフと国別割合を正しく表示できるか。部分取得・行数上限・旧形式を偽の 0 や正常値にしないか。
2. 7 日・30 日、前期間比を各データセットごとに有効化する条件が十分か。比較不可を適切に伝えられるか。
3. 旧 WAF 5 項目を必須監視から外しても、新しい必須データの実障害と他サービスの障害を Digest が検知するか。
4. Access、秘密情報、個人アクセス情報の非保存、既存 GCP 画面、段階配備と項目単位の戻し方に抜けがないか。
5. 国別の位置・イベント数について、利用者が人数・所在地・攻撃成功と誤解しないか。PC/スマートフォンとキーボード・読み上げで意味が伝わるか。

一次レビューの 15 件の採否と条件付きの扱いは計画 §8 に記録した。追加報告を受けた Codex の判断は、**24 時間の同一 1h 照会からの時系列と国別集計は GO**、地図の塗り分けは実素材とコードの照合後、7/30 日の Adaptive 全件割合は母数と完全性の証明後とする。未確定のセキュリティ系列は主目的から分離する。Digest 必須集合、問い合わせ予算、OCI 稼働 checkout との差は実装中に確認し、契約を確定する前に記録する。
