## 所見の補足

レビュー所見4の「CF未評価の場合でもcollector_errors」は広すぎるため、採用記録では次のように区別する。

- 実際の取得失敗、期限不明・期限切れ、契約不正による利用不能: 固定のCF errorを保持し、既存状態の優先順位を維持する。
- 初回対象外の利用枠・危険度の未評価: 固定の範囲説明を表示し、正常な収集までcollector errorにしない。last_success更新を恒常的に止めない。

「完全に防ぐ」等は、確認した経路における実装方針・テスト結果として扱う。本番での安全性や不具合不存在を保証する結論にはしない。
