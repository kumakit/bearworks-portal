## 決めたい内容

1. 7日・30日の Adaptive 時間別・国別・全体値を同一区間・同一フィルタで照会し、時間数、各和と全体値の一致、国別行上限未達、重複・部分エラーなしを**毎回検証**する条件で、推計の時系列・割合・地図を公開してよいか。今回の一致は単発実測であり、今後も成立するとは扱わない。
2. `sampleInterval` が行や集計ごとに異なる場合、いずれかが1を超えればブロックを `estimated` とする規則が妥当か。国別と時系列で精度が異なる場合は混ぜず、当該表示を止めるか、推計として統一するか。
3. 直前24時間の1h系と直前7日のAdaptive系を独立照会し、現行・前期間の粒度、対象、境界、完全性、精度が一致する場合だけ増減を示す設計が妥当か。両方0件の増減率やサンプリングを伴う比較の日本語説明も確認したい。
4. v2 へ `trafficPrevious24h`、`trafficSeries7d`、`countryTraffic7d`、`trafficPrevious7d`、`trafficSeries30d`、`countryTraffic30d` を独立ブロックとして追加し、Portal を先に配備する契約・配備順が安全か。既存24時間、v1、Digest、他サービスへの影響と、期間別・国別だけの障害隔離を確認したい。
5. 30日対直前30日は保持境界により利用せず、完全な60日履歴と保存規則が整うまで比較不可とする判断が妥当か。履歴を今回開始する必要があるか、それとも別フェーズとするか。
