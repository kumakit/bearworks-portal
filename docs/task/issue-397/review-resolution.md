4. 実装へ進む明示的な承認を得る。現在は文書更新だけ。

- 収集間隔、許容遅延、時刻同期、誤差上限・再同期間隔。
- Pagesの対象・契約・ビルド集計・月境界。確認できない利用枠ルールは無効。
