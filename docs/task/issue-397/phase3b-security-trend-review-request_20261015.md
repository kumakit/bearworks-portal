# Issue #397 Phase 3B 計画レビュー依頼（読み取り専用）

[計画案](phase3b-security-trend-plan_20261015.md)を読み、現行の Apps/Portal 契約と照合してください。実装、ファイル変更、push、Issue 更新、本番操作は行わないでください。資格情報、個別イベント、本番の生データは扱わないでください。

利用者へ分かる言葉で、次の点を確認してください。

1. Cloudflare が示す「抽出を含む Firewall イベントの時間別集計」を「セキュリティイベントの推移（参考）」と表示して誤解を招かないか。攻撃件数や遮断件数と受け取らせない説明になっているか。
2. 返らない時間を0件にせず、取得遅延・抽出の可能性を扱えるか。30日分は実測で全行が抽出集計だったため、値とグラフの示し方が妥当か。
3. セキュリティ系列だけが失敗・期限切れになっても、アクセス推移、国別アクセス、Digest の必須判定に影響しない契約か。Apps から Portal への反映順と旧形式の扱いは安全か。
4. 24時間・7日・30日の範囲、時刻境界、上限、部分応答、重複時刻を試す条件が十分か。
5. この計画のまま採用してよいか。採用前に必ず解消すべき点があれば、根拠と変更先を示すこと。

確認済みの事実、推測、未確認事項を分けて報告してください。指摘には重要度、理由、計画の変更先を付けてください。履歴保存と30日アクセス前期間比は別フェーズです。
