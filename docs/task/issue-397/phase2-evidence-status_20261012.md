# Issue #397 Phase 2 追加実測

確認日: 2026-10-12 JST。対象は既存 Apps 認証主体で照会できる bearworks.uk ゾーン全体。認証情報、zone ID、個別リクエストは記録しない。

## 方法

既存 OCI Apps 環境の設定を読み、[読み取り専用スクリプト](./probe_cloudflare_phase2.py)を標準入力から実行した。スクリプトはリモートへ保存していない。Cloudflare GraphQL `httpRequestsAdaptiveGroups` の時間別、国別、全体値を、同じ `datetime_geq` / `datetime_lt` 条件で一つの応答から取得した。終了は直近の UTC 正時、区間は開始を含み終了を含まない。現行7日、直前7日、現行30日を独立照会した。さらに `httpRequests1hGroups` で直前24時間を独立照会した。再照会でも下表の判定は同じだった。

| 期間 | 時間別 | 国別 | 同一条件の母数 | 推計 |
| --- | --- | --- | --- | --- |
| 直前24時間 | 24/24 個、重複・欠けなし | 照会対象外 | 時間別のみ照会 | サンプリングなし |
| 現行7日 | 168/168 個、重複・欠けなし | 51行、重複なし、500行上限未達 | 時間別和・国別和・全体値が一致 | 時間116行、国21行、全体1行でサンプリングあり |
| 直前7日 | 168/168 個、重複・欠けなし | 43行、重複なし、500行上限未達 | 同上 | 時間117行、国22行、全体1行でサンプリングあり |
| 現行30日 | 720/720 個、重複・欠けなし | 86行、重複なし、500行上限未達 | 同上 | 時間417行、国32行、全体1行でサンプリングあり |

今回の独立した全体値との一致は、同じ照会条件で国別割合と地図の濃淡を計算できる根拠となる。ただし値は推計であり、サンプリング率は行ごとに異なる。単発の一致を今後の保証とせず、毎回、時間数・境界・重複・国別行数上限・同一母数・部分 GraphQL エラー・サンプリングを検査する。条件を満たせない期間は `FULL` の割合や地図の濃淡を表示しない。欠けた時間を 0 で補わない。

## 採用判定

- **7日・30日のアクセス推移と国別割合・地図: 条件付き GO。** 両期間とも `estimated` と明記し、各収集で上記の完全性と一致を検証する。24時間の `httpRequests1hGroups` の厳密値と同じ母数として混ぜない。
- **24時間対直前24時間の増減: 条件付き GO。** 直前窓を 1h 系で取得し、現行・前期間とも24点、同じ対象・精度・欠損なしを確認してから比較する。
- **7日対直前7日の増減: 条件付き GO。** 両窓の境界、168点、同じデータセット・フィルタ・推計区分、部分エラーなしを各実行で確認したときのみ、推計同士の参考比較として表示する。片方だけ失敗した場合は比較値を隠し理由を示す。
- **30日対直前30日の増減: NO-GO。** `notOlderThan` 約31日で60日窓に足りず、同一定義の完全な保存履歴はまだない。「蓄積中」等と表示し、比較値は出さない。

Phase 0 証跡の「7/30日国別割合・濃淡」と「7日比較」は、追加照会前の保留判定だった。今回の実測によって条件付き GO へ更新する。安全条件の詳細は[実装計画](./implementation_plan_20261011.md)に反映する。
