# Issue #410 Phase 0 成立性調査

調査日: 2026-10-24 JST。根拠は公式公開資料の取得原本とオフライン検算。最終記事の検証・公開確認は未実施。

## 判断

**2016-09-30→2026-09-30の10年比較は、公式Excel系列で進められる。地図は今回は採用せず、地域別比較チャートにする。** 市全体と年齢3区分は全市の公式総数を使い、町丁の比較は確認できた変更対象・未解決対象8町丁を除いた191町丁を候補にする。残る町丁の地理的不変を完全に立証したという意味ではなく、公式集計単位の比較と限界を明記する。

比較手段・対象の決定に必要なPhase 0調査を実施した。CSVとの差の原因、2025年町区域変更の施行日、期間内変更の完全な網羅は未解決として残す。解決済みと見せず、対象資料と表示範囲を絞って実装する案をr2へ提示する。

## 対象日・総数・定義

## 町丁対応

- 両端の年齢Excel内の住所・コード一覧から、199件の町丁コード（5桁文字列）を取得。両端でコード集合と正規化町名が完全一致した。数値化されたCSVコードは検査用に5桁へ戻す。
- 全角/半角、IVS、丁目の一～十/算用数字、絹ヶ丘/絹ケ丘を明示的な表記差として扱う。あいまい一致は使用しない。
- 2016 CSVのコード16200の名称は `大^1琺`。文字を推測して書き換えず、人口・年齢Excelのコード/正式名「大塚」を根拠にする。鑓水・大塚のIVSも保持原本と正規化後を区別する。
- コード・町名の一致は境界不変の証明ではない。[上野第二の公式住所変更資料](https://www.city.hachioji.tokyo.jp/kurashi/kosekijumin/008/001a/p032860.html)と[2022年議案概要](https://www.city.hachioji.tokyo.jp/shisei/001/001/007/002/p031262_d/fil/gaiyou.pdf)で、上野町、小門町、台町3・4丁目の相互編入と2024-08-10の住所変更を確認。
- [2025-09-10総務企画委員会の公式会議録](https://www.city.hachioji.tokyo.dbsr.jp/index.php/734981?Id=6155&Template=document)の第131号説明では、川口町→上川町、西寺方町→美山町への編入を予定し、施行日は換地処分公告翌日。具体日が分からず、2026年9月末時点の施行を断定できない。[可決一覧](https://www.city.hachioji.tokyo.jp/contents/shigikai_1/gikainokatudou/honnkaigi/reiwa7/p036001.html)は2025-09-22可決を示す。会議録の「住所が変わる市民はいない」は人口増減や境界無変更の証拠に置き換えない。
- 以上8町丁を今回の町丁増減ランキングから保守的に除外。対象は `region-exclusions.json`、全199件の対応と対象状態は `evidence/normalized/town-code-crosswalk.csv` に残した。全市総数・全市年齢表にはこの8町丁も含む。

## 地図の判定

八王子市のみの公式ファイルを取得できた。

`https://www.e-stat.go.jp/gis/statmap-search/data?dlserveyId=A002005212020&code=13201&coordSys=1&format=shape&downloadType=5&datum=2011`

- 令和2年国勢調査用、JGD2011のShape/DBF/SHX/PRJ。297図形、HCODEは全件8101、正規化した町丁名は199。
- 人口表との**名称候補一致**は199/199、人口カバー候補は両年100%。これは地理的な同一性を認定した結合率ではない。複数ポリゴン・飛び地があり、同じKEY_CODEの複数図形を誤って二重加算しない設計が必要。
- 8町丁を除くと191/199（95.98%）。人口を分母にすると2016年94.20%、2026年94.41%で、事前基準の各95%に届かない。地域変更が未解決の西寺方町・美山町は、除外前の診断用減少上位10にも入る。
- 名称候補100%を「地図合格」とはしない。比較可能性を厳しく扱うと人口カバー基準と主要地域の条件を満たさないため、**今回の公開版は地図不採用**。表と横棒/2時点比較チャートへ切り替える。
- 上野4町丁や川口関連2組を合算する案は可能性がある。ただし境界図の合算範囲と全期間の区域対応の追加検証が必要で、名称一致だけで合算を正当化しない。1本の記事のために未検証の地図を追加せず、現段階はグラフ案を採用する。将来地図を再採用する場合も事前基準を変えず再検証する。

これは境界データの利用許諾がないための見送りではなく、比較地理の根拠と対象範囲による判断。

### 区域変更関連の除外8町丁を隠さない

除外8町丁は、公開する町丁表の末尾に「比較対象外」として両時点の参考人口・理由を載せる。順位・人数差・率は付けず、地理的に同一の範囲を比較できると示唆しない。上野町、小門町、台町3/4丁目は変更確認済み、川口町、上川町、西寺方町、美山町は施行時点未確認として区別する。

美山町/西寺方町が除外前の診断で減少上位10に入ったことを方法欄に記載する。対象を除外したランキングを全市の増減順位と呼ばない。主図の近くに「191町丁・2026年9月末全市人口の94.4%」と「8町丁は区域変更確認済み、または施行時点未確認のため比較対象外」を常時表示する。これは「CSV差の8町丁」と別の集合であり、文中で名前を区別する。

191町丁の小計は530,676→528,044人。全市の563,327→559,320人と別に保持する。人数差図は191町丁、率の主順位は始点100人以上の190町丁、宇津貫町（始点65人）は小人口1町丁として別表示。全市年齢構成比は各年の全市人口を分母とする。図/カードごとに「対象・分母・基準日」を記載する。

### CSV差の方法欄文案と版の情報

> 本記事は市の町丁別人口Excelと年齢別Excelを使用します。二つの表は全町丁で一致しましたが、同じ発行元の資料間の内部整合を確認したものです。公開CSVとの差は2024年-3人、2025年+9人、2026年+9人（いずれもCSV−人口Excel）で、原因は未確認です。2026年CSVを使うと559,329人、2016年比3,998人減となり、Excelの4,007人減と減少方向は同じです。この点は、町丁ごとの順位や他の指標も変わらないことを保証しません。

取得時のHTTP Last-Modified（JST換算）は、2026年年齢Excelが2026-10-24 01:04:36、人口Excelが同01:06:34、CSVが同02:22:34。CSVの2024/2025年版にも同じLast-Modified値が付いていた。掲載ページの更新表示はCSVが2026-10-01、両Excelページが2026-08-15。これらはHTTPリソースやページの日時で、統計値の改訂日・最新版の正しさ・差の原因を確定する根拠にはならない。原値・取得日時・hashは `evidence/review-checks.json` と `evidence/retrieval.json` に保持する。

公開前には採用原本を別版の保存先へ再取得し、採用版hashと比較する。変化した場合はデータ・本文・検算を更新し、元の証跡は上書きしない。
