# Issue #410 実装計画r1 Sonnetレビューの採否

受領日: 2026-10-24 JST
対象: `docs/task/issue-410/implementation_plan.md` r1 → r1.1
レビュー元: ユーザーがこのチャットに提示したSonnetのレビュー。以下は指摘の要約と司令塔の採否であり、レビュー原文の全文保存ではない。

## レビューの範囲と判定

レビュー元の範囲: 「計画文書の読解のみ」。リポジトリ、Issue、公式資料は未確認。
レビュー元の判定: 「条件付き承認。要修正の1〜4 を計画 r1.1 に反映すれば、Phase 0 に進めます」。PR分割はr2での確定を推奨。

司令塔の判断: 4項目をr1.1へ反映し、Phase 0へ進むための計画上の条件を解消した。これはPhase 0のデータ検証完了、ユーザーの調査続行指示、記事実装や公開承認の代わりではない。今回の依頼はレビューの検討として扱い、文書修正まで実施。

## 採否と理由

| 指摘 | 採否 | 反映・理由 |
| --- | --- | --- |
| 必須1: ライセンス/再配布の判断を前へ | 採用 | Phase 0の独立ゲートに昇格。原本・変換CSV・集計表/JSON・境界・SVGごとにallow/deny/unknownを記録。attributionText等をmanifest必須化。境界条件が合わなければ地図と配布物の両方を見送る。全資料へCC BYを一律付与しない。 |
| 必須2: 日付の整合性/実在確認 | 確認手順を採用、日付矛盾という評価は不採用 | 2026-10-24に2026-09末資料が掲載されていること自体に矛盾はない。r1もリンク掲載のみ確認、内部解析未実施と記載していた。ただし先頭の作業を内部対象日・総数・資料間一致の検査へ強化。資料が取得/解析済みとは扱わない。 |
| 必須3: 10年比較の固定を避ける | 明確化として採用 | r1にも期間代替はあったが、タイトル/description/図題をPhase 0後に決定すると明記。2016→2025、2015→2025、2016年3月→2026年3月を未検証の代替候補として追加。10年の長さより比較可能性を優先。 |
| 必須4: 地図閾値を事前登録 | 補強して採用 | 両時点の人口カバー率・町丁件数対応率が各95%以上。人数と率の増加/減少各上位10（同順位含む）が全件結合。率は始点100人以上。人口分子は同一地域集合、件数は元の公式行。地域照合不確実・地理的偏り・比較不能地域の影響も別判定する。閾値は編集方針であり公式の品質基準ではない。 |
| 推奨: 3PRへ分割 | 案として採用、r2で確定 | データ→記事→導線の依存順。固定版/hashと対象SHAを合わせ、最終組合せの統合CIを実施。レビュー単位と公開単位を分ける。先行PRのみの本番公開を避け、導線非掲載を非公開の根拠にしない。 |
| 推奨: Python判断/Excel変換を早める | 採用 | Phase 0で変換試行とツール確定。原本と変換後のhash、変換器版、列対応を記録。総数はCSV優先、年齢別のExcelだけ必要に応じて処理。xlrd/openpyxlは候補で未導入。 |
| 推奨: 年齢階級の不一致 | 採用 | 15歳/65歳の境界を厳密に作れるか確認。1歳刻みや適切な5歳階級なら再集計可能。別公式表・共通区分・別期間を候補化し、階級内の比例配分は禁止。 |
| 推奨: 意外な発見を約束しない | 採用 | 必須節を「分からなかったこと・限界」へ変更。意外な発見は実際にあった場合のみ。任意見出しの変更・削除を許可。 |
| 推奨: main基点とcherry-pick | 条件を補って採用 | 同期状態を確認したmain SHAから専用branch/worktreeを作る。計画だけの独立commitは対象確認後cherry-pick可。現在は未追跡なので直接cherry-pick不可、commit前なら対象文書だけコピー＋hash照合。#408 branchは基点にしない。今回はGit変更なし。 |
| 推奨: 工程表は役割中心 | 採用 | 計画統括・実装・編集・検証を主表記とし、モデル名は補足。受領済みr1レビューと未実施r2レビューを分離。 |
| 軽微: 気候ページのパス統一 | 採用 | `app/(monetized)/labs/hachioji-climate/page.tsx` に統一。 |
| 軽微: /labsは新規 | 既存記載を維持 | ファイル表の「新規Labs入口」で明示済み。 |
| 軽微: JSなし/SSR早期確認 | 目的を採用、実装方針を明確化 | RechartsがSSRでSVGを返すことを要件にせず、初回サーバーHTMLに本文・表・出典を置く。記事の最小試作時にJS無効で確認する。 |
| 軽微: 公開承認ゲート | 維持 | 変更不要というレビューに同意。 |

## 補助検討と検証

- mission-control-flowに基づき、Lunaへ閾値、PR依存と公開境界、JSなしの表示の一般設計だけを読み取り専用で分担。Issue本文・非公開資料は渡していない。
- 分母固定、同一地域集合、未対応地区の偏り、結合前ランキング、直接URLによる意図しない公開、初回HTML確認を追加した。
- 現行文書と作業ツリーを確認。今回の変更は計画関連文書のみ。原本取得・人口集計・境界照合・実装テストは実施していない。
- 文書のUTF-8読出し、改訂番号、主要な修正項目、対象外変更の有無を確認する。コード未変更のためbuildは今回の検証対象外。

## 残る作業

Phase 0で対象日/総数・公開可否・年齢/地域対応・事前閾値を検証し、r2に実測の根拠とPR分割を記録する。r1へのレビューは受領済みだが、r2の実データに基づく成立性レビューは別途必要。
