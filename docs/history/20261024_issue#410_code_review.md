# Issue #410 独立コードレビュー

日付: 2026-10-24 JST
担当: Luna（読み取り専用）

## 初回レビュー

主要なPhase 0条件、記事の数値・対象範囲、サーバー描画と一覧導線は整合していた。次の3点を要修正として報告した。

1. manifestの末尾がPhase 0時点の「公開資産なし」を現在の状態と区別していなかった。
2. 増減率ランキングの順位と同率判定が、表示用に4桁丸めした値を使っていた。
3. ランキング順位と境界同率の自動回帰検査が不足していた。

## 修正と再レビュー

- manifest注記をPhase 0時点の説明と、実装後のplanned fieldsに分けて明記。
- 増減率順位は `delta1 * baseline2 - delta2 * baseline1` の交差積で丸め前の正確な比率を比較し、表示値の丸めから独立させた。近似同率と厳密同率の回帰テストを追加。
- bundle validatorで人数順位・率順位の4一覧を再計算し、順序と同率の完全性を比較。manifestのplannedFilesと公開フォルダー内の実ファイル名集合も照合。

Lunaの再レビューで3点の解消を確認し、新たな具体的指摘はなし。レビューはコードと文書の読解であり、Luna側ではテスト・validatorを実行していない。CI実行、実機タッチ確認、独立した元データ再取得/再集計は対象外。これらのうちテスト・validatorは司令塔がローカル実行済み。
