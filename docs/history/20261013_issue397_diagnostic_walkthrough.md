# Issue #397 定期収集の診断記録（2026-10-13）

## 変更

- Apps の Cloudflare 収集と Digest に、1回ごとの状態だけを記録する診断行を追加した。各項目の取得状態、範囲、分類済みエラー、利用可否（利用可・期限切れ・契約不整合など）を残す。アクセス数、国、IP、API応答、例外本文、認証情報は記録しない。
- 収集と Digest は同じ形式の実行識別番号で照合できる。無効にした項目は必須集合に含めない。公開データと障害判定は変更しない。
- 共通の説明方針は、mission-control の `global_config/CODEX_AGENTS.md` に別変更として追加した。
