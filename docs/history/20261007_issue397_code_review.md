3. **部分取得・GraphQLエラーの処理**: HTTP 200内のGraphQL `errors` や `data=null` の検知、Pagesの `RESULT_LIMIT` 等が適切に `PARTIAL` や `ERROR` に振り分けられ、偽の0件として扱われません。
4. **Digestとlast_successの安全な連携**: CF未評価の場合でも `collector_errors` 経由でエラーを伝えつつ、他サービスの監視値を維持して `last_success` の恒常的な更新停止を防いでいます。
5. **AI自由文の固定化**: CF未評価時には、決定論的なフォールバックロジックにより「Cloudflareの利用枠と危険度は判定していません」等の固定案内が生成され、AIの幻覚による「Cloudflareは安全です」という断定を完全に防いでいます。
6. **認証・キャッシュと時刻の保守的扱い**: 既存のAPI認証・`no-store`・405応答を維持しています。ブラウザの `performance.now()` 単調時計を用いた往復遅延(RTT)計算と再同期ロジックにより、スリープ復帰や遅延を極めて保守的に扱っています。
7. **並行処理のクリーンアップ**: `AbortController` による並行fetchのキャンセル、コンポーネントアンマウント時や可視性変更時の状態リセット(`clock.current = null`)により、古い値が残留しません。

9. **テスト網羅性**: 提示されたテストコードは境界値、異常系、古いペイロードの拒絶をカバーしており、合成fixtureを通じた契約確認の仕組みも機能しています。
