# 八王子を数字で読み解く 第5弾の実装記録

## 記事とデータ

- `/labs/hachioji-students` に学生数の折れ線、学校の集計範囲と学生アンケートの図を追加した。第4弾と相互リンクし、Labs一覧、サイトマップ、SNS共有画像、記事の構造化データを設定した。
- 前作と同じ紺色の冒頭と3:2の挿絵を採用した。今回の挿絵は前作の色調を参考にした新規のAI生成画像で、架空の大学キャンパスを描いた。PCでは画像を文章の右、スマホでは下に置いた。
- 市内の大学等の学生数は2006年104,130人、2023年89,763人で、14,367人（13.8％）減った。2024年の90,768人と2025年の91,540人は「八王子市の概要」の参考値として掲載した。各年の基準日は5月1日で、長期系列との定義の一致は未確認。
- 公開JSONは市の原図を転記して照合した固定データ。原資料へのリンクと、年次値・学校区分・基準日・アンケートの分母を含む。記事と図表はそのJSONを直接参照する。`node scripts/validate-hachioji-students-data.mjs` でネットワークなしに数値と増減率を再確認できる。原資料の数値を出典とともに掲載し、元資料の図版や写真は使用していない。

## 担当と確認

- Antigravity が公開資料を使って日本語初稿を作成した。Codex が表現を照合し、実装時に2024～2025年の参考値と移転事例を反映した。
- Luna は2024年以降の公開系列の比較可否を調査した。Codex は2024年度版と2025年度版の資料で基準日・人数を照合した。
- PC幅1440pxとスマホ幅390pxで冒頭を確認した。スマホで横はみ出しがなく、折れ線と数値表の開閉を確認した。
- 新規データの数値検証、Next.jsのビルドと型検査、第4・5弾のローカル配信検証に合格した。配信検証はHTML、テスト広告ID、画像とデータの応答、記事間リンク、サイトマップを確認した。リポジトリ全体のlintはエラー0件、既存の警告3件だった。
- 第4弾の既存公開ファイルはWindowsの改行変換で通常のハッシュ検証が失敗した。Gitの内容を改行変換なしで一時展開した環境では、既存の全公開データ検証が通過した。
- 開発時の依存関係監査で既存の Next.js 16.4.3 が検出された。記事の実装では依存関係を変更していない。Workers CI は依存関係監査に合格する必要があり、本番公開には別途承認が必要。
