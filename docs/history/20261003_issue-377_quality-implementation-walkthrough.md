## ローカルで変更した内容

1. 高尾山天候記事から、原本で裏付けられない発生日数、降水割合、28.6%、危険度点数、観測と再解析の混同を除去。雲の仕組み、データ種別、同時割合と条件付き割合の分母を説明する教材へ改訂。選択式の表示は確認事項のみを提示し、予報や安全判定をしない。
2. 同じ旧モデル集計に依存した高尾山装備記事から「装備必須日数」「事故確率」と採点式シミュレーターを除去。[高尾ビジターセンター](https://takaovc.ces-net.jp/?page_id=273)、[八王子市](https://www.city.hachioji.tokyo.jp/kankobunka/001/004/p003393.html)、[気象庁](https://www.jma.go.jp/bosai/)の案内を照合する手順に改訂した。関連リンクの旧題名・旧判定文も更新。
3. 統計ガイド8本の説明を点検し、CBTの仕様の断定、p値・信頼区間・検定の前提、分布、回帰、ANOVA、標本抽出の表現と個別出典を補強。関連する代表例題の標本抽出の説明も修正。日付は「内容更新日」と表示し、最終承認日とは区別する。
4. トップにガイド・例題・分析記事の三つの入口を追加。プライバシーポリシーにGoogle広告のCookie、過去アクセスに基づく広告、無効化先を追加。サイトマップ検証では静的14パス、ガイド8slug、例題30slugを公開データとは独立した期待値として照合する。
5. 旧高尾山天候bundleの検証ログを「履歴ファイルの同一性と内部算術」に限定した。旧数値の妥当性・利用許諾を検証したように読めるログを削除した。Linux CIの旧ヒーロー画像検査は、改訂記事の本文検査に置換した。
6. 横断点検で八王子の冬の朝の記事の均質性説明と時間値ペア数の不一致を発見。東京観測所の移転開始時刻を[気象庁告知](https://www.jma.go.jp/jma/kishou/know/kansoku/info/20141202_tokyo_rojo.html)で確認し、移転前の2日が朝7時集計に含まれることを明記した。固定bundleの有効ペア数25,859組を表示し、2日を除く1,076日の朝7時差の感度確認を併記した。固定r1とlockは変更していない。

主張ごとの根拠と削除理由は[対応表](../task/issue-377/quality-improvement-20261003/claim-evidence.md)、統計ガイドの確認範囲は[8本の確認表](../task/issue-377/quality-improvement-20261003/guide-review.md)を参照。
