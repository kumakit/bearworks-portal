# Issue #378 記事・学習体験の設計レビュー結果

提供された主資料 `content-design.md`（レビュー版 r1）および補助資料 `implementation_plan.md` に基づき、記事構成・図解・統計検定2級学習体験の設計レビューを実施しました。

## 1. 結論

**条件付き承認**

### 理由
気象データの特性（時系列の自己相関、アメダスの観測限界、欠測や非観測の扱い）と、統計学の基礎（対応のある差の検定、母平均の区間推定、p値や信頼区間の誤読防止、記述統計と推測統計の明確な境界）に対する配慮が極めて綿密であり、全体設計は非常に優れています。  
ただし、**①「平均差の信頼区間」と「個々のイベントのばらつき」の混同防止注記の追加**、**②気温相関における「見かけの相関（日周・季節交絡）」への言及**、**③スマートフォン表示におけるヒストグラムと箱ひげ図の重複整理と代替表示の具体化**、の3点を補強することを条件として承認とします。

### Major（学習・読書体験や実装を妨げる不足）

#### 指摘 1: 平均差の95%信頼区間図における「平均の不確かさ（SE）」と「個体値のばらつき（SD）」の混同防止
- **対象ファイル・見出し**: `content-design.md` → `## 分析と統計検定2級の対応`（L78）、`## 「統計検定2級の道具」欄`（L98-106）
- **問題**: 「各イベントの差を点で表示し、イベント集合の平均差に95%信頼区間を付ける」設計において、初学者が「95%信頼区間の中に95%のイベント（点）が入る」と誤読するリスクへの対策が明記されていません。
- **理由**: 統計検定2級の学習者が最も混同しやすいのが「標準偏差（$s$：データのばらつき）」と「標準誤差（$SE = s/\sqrt{n}$：標本平均のばらつき）」の違いです。各イベントの差（点）が散らばっている中央に幅の狭い信頼区間が描かれると、「なぜ点が区間の外にこんなにあるのか？」という誤解が生じます。
- **修正案**: 
  - 図のキャプションおよび学習欄に以下の趣旨を明記する：  
    > 「信頼区間は『母平均（平均的な差）がどこにあるかの不確かさ』を示す帯であり、個々のイベントの差がこの幅に収まることを意味するものではありません（標準誤差と標準偏差の違い）。」
  - 可能であれば、図上に「平均差の95%信頼区間（エラーバー）」とともに、背景に「個々のイベントの差の要約（中央値や四分位範囲など）」を別レイヤーとして視覚的に区別して注記する。

#### 指摘 2: 2地点気温の散布図における「見かけの相関（共通要因による交絡）」の明記
- **対象ファイル・見出し**: `content-design.md` → `## ページの流れ`（L52 セクション6）、`## 分析と統計検定2級の対応`（L80）
- **問題**: 散布図および単回帰分析において、日周変化や季節変化などの「外部共通要因」による見かけの相関についての学習上の注意が不足しています。
- **理由**: 冬期の2地点気温は、同一の寒気流入や昼夜のサイクルによって同時に上下するため、必然的に強い正の相関を示します。これを読者や学習者が「都心の気温が八王子の気温を直接決めている（因果関係）」、あるいは「単純な2変数だけの関係」と誤読しないよう、統計検定2級の重要テーマである「交絡因子・見かけの相関」を明確に位置付ける必要があります。
- **修正案**:
  - セクション6の小見出し・解説に「気温が連動する背景（同一の気団・日射という共通要因）」を明記する。
  - 学習欄に「相関係数が高くても、第3の変数（寒気・日照・季節）が両者を同時に動かしている可能性がある（見かけの相関と因果の区別）」という解説項目を固定する。

#### 指摘 3: セクション4におけるヒストグラムと箱ひげ図のモバイル表示の最適化
- **対象ファイル・見出し**: `content-design.md` → `## ページの流れ`（L50 セクション4）、`## 画像とレイアウト`（L68）
- **問題**: セクション4で「ヒストグラム＋並列箱ひげ図」を両方掲載すると、スマートフォン閲覧時に縦スクロール量が過大になり、読書テンポを損なう恐れがあります。
- **理由**: ヒストグラムと箱ひげ図はどちらも「降水時の気温分布」を表す図であり、情報が部分的に重複します。特にモバイル画面ではグラフが縦積みになるため、2地点×2種類で図が連続すると要点がぼやけます。
- **修正案**:
  - デフォルトの常時表示図は、2地点の比較（中央値・四分位範囲・外れ値）が1枚でコンパクトに把握できる**「並列箱ひげ図」**を主図とする。
  - ヒストグラムは「分布の詳細（峰の数・歪み）を見る」ためのタブ切り替え、またはアコーディオン展開とする。

### Minor（表現の改善・より良い読書体験のための提案）

#### 指摘 4: 「八王子駅前の中継場所」と「アメダス八王子観測地点」の微気候・標高差の注記
- **対象ファイル・見出し**: `content-design.md` → `## 導入案`（L36-40）、`## ページの流れ`（L49 セクション3）
- **問題**: テレビ中継される八王子駅前（商業地・ペデストリアンデッキ等）と、気象庁アメダス八王子（元横山町付近、標高約120m）の微小な環境差に対する導入時の言及が控えめです。

- **修正案**: セクション1〜2の注記またはセクション3の地点説明に、「テレビ中継でよく映る駅前周辺と、気象庁のアメダス観測地点は近接していますが、市街地環境や標高など局所的な違いがあります」と1行補足を添える。

#### 指摘 5: 湿度データ不可用時のセクション7（雨雪境界）の代替案具体化
- **対象ファイル・見出し**: `content-design.md` → `## ページの流れ`（L53 セクション7）、`## 分析と統計検定2級の対応`（L81）
- **問題**: アメダス八王子の過去の相対湿度は提供開始年が比較的新しいため、長期解析で利用できない可能性が高いですが、その場合のフォールバック表現が「条件が揃えば」とやや抽象的です。
- **理由**: 調査後に慌てて設計変更するのを防ぐため、事前にフォールバックを確定させておく必要があります。
- **修正案**: 八王子の湿度が使えない場合の確定代替案として、「地上気温のみによる雨雪判定（例: 2℃以下・0℃以下）の頻度集計表」または「湿度が観測されている東京都心側の雨雪条件を基準とした対照表」にフォールバックすることを明記する。

  **雪のニュース、また八王子？ ――「中継の定番」を気象データで確かめる**
- **リード文（120字）**:  
  「都心は冷たい雨なのに、テレビの八王子駅前はなぜか雪景色――そんな中継を目にしたことはありませんか。同じ東京で本当にそこまで差があるのか。テレビの印象を仮説に変え、気象庁の長期データと統計の道具を使ってその正体を確かめます。」

## 5. ミニ設問案（5問）

実測値が未確定な段階であるため、**「グラフ・統計概念の正しい読み取りと誤読防止」**に焦点を当てた設問案を作成しました。

### 第1問（セクション4配置: 分布の要約と箱ひげ図）
- **問い**:  
  降水時の気温データを集計したところ、平均値よりも中央値の方が高くなっていました。箱ひげ図とヒストグラムから読み取れる分布の特徴として、最も適切なものはどれですか。
- **選択肢**:
  1. 気温が極端に高い日（外れ値）が複数存在し、全体の平均値を引き上げている。
  2. 気温が極端に低い日（強い寒気の流入など）が一部にあり、平均値が左（低温側）へ引き下げられている。
  3. データが左右対称の正規分布に従っており、外れ値は存在しない。
  4. データの半分以上の観測値が、平均値よりも低い気温を示している。
- **正答**: **2**
- **短い解説**:  
  平均値は外れ値の影響を強く受けます。平均値が中央値より低い（平均値 < 中央値）場合、低温側に長い裾野（または極端な低温の外れ値）が存在して平均を引き下げていることを示します。
- **誤答しやすい理由**:  
  「平均値が高い＝データが大きい側に偏っている」と直感的に混同し、大小関係と歪みの方向（右に歪む／左に歪む）を取り違えやすいため。

---

### 第2問（セクション5配置: 母平均の区間推定と標準誤差）
- **問い**:  
  降水イベントごとの八王子と東京都心の平均気温差について「95%信頼区間が $[-2.1℃, -1.5℃]$」と推定されました（学習用の仮想データ）。この結果の解釈として、統計学的に最も適切なものはどれですか。
- **選択肢**:
  1. 今後発生する降水イベントの95%において、八王子は東京都心より1.5℃〜2.1℃低くなる。
  2. 真の母平均の差が、95%の確率で $-2.1℃$ から $-1.5℃$ の間に含まれる。
  3. 母平均の差が0である確率が5%以下であることを直接証明している。
  4. 同様の標本抽出と区間推定を多数回繰り返したとき、作られた信頼区間のうち約95%が真の母平均の差を含む。
- **正答**: **4**
- **短い解説**:  
  頻度論における信頼区間は、「推定を繰り返したときに真の母数をカバーする割合」を表す手法の信頼性を意味します。個々の事象がこの区間に入る確率（予測区間）ではなく、また一度求めた特定の区間に真の母数が入る確率を95%と表現するのも誤りです。
- **誤答しやすい理由**:  
  統計検定2級の最頻出トラップである「95%の確率で真の値が入る（選択肢2）」や「個々のデータが95%入る（選択肢1）」を直感的に正しいと誤認してしまうため。

---

### 第3問（セクション5配置: 対応のある2標本と標本単位）
- **問い**:  
  八王子と東京都心の気温差を検証するにあたり、「1時間ごとの測定値（計1000時間）」をそのまま使って対応のあるt検定を行うべきではない最大の統計的理由は何ですか。
- **選択肢**:
  1. 標本サイズが1000を超えると、t分布ではなく正規分布を使わなければならないから。
  2. 気温の時別データには強い系列相関（直前の時間との依存関係）があり、観測値同士が独立していないから。
  3. 2地点のデータは対応関係にあるため、差の検定を行うことが原理的にできないから。
  4. 降水量が地点ごとに異なるため、気温の平均値を計算することが数学的に許されないから。
- **正答**: **2**
- **短い解説**:  
  t検定の標本が互いに独立であるという前提が必要です。連続する時間の気温は強く連動（系列相関）しているため、時別データをそのまま1観測として扱うと実質的な独立情報量が過大評価され、標準誤差が過小となってp値が不当に小さくなります（第1種の過誤の増大）。
- **誤答しやすい理由**:  
  「データ数（サンプルサイズ）は多ければ多いほど検定の精度が上がる」と思い込み、時系列データの自己相関による前提違反を見落としやすいため。

### 第4問（セクション6配置: 相関関係と交絡因子）
- **問い**:  
  冬の降水時における八王子と東京都心の気温をプロットしたところ、相関係数が $r = 0.92$ と非常に強い正の相関を示しました。この結果から結論づけられることとして、最も適切なものはどれですか。
- **選択肢**:
  1. 東京都心の気温が上昇することが原因となって、八王子の気温が上昇している（因果関係がある）。
  2. 2地点の気温は連動して上下する強い直線関係にあるが、寒気流入や昼夜変化など共通の要因（交絡因子）による可能性がある。
  3. 相関係数が高いため、八王子と東京都心の気温には有意な温度差が存在しないことが証明された。
  4. 単回帰直線を当てはめれば、東京都心の気温から八王子の気温を誤差ゼロで完全に予測できる。
- **正答**: **2**
- **短い解説**:  
  「相関関係は因果関係を意味しない」は統計の鉄則です。強い相関があっても、それは同じ低気圧や日射という「第3の共通変数」の影響を受けている可能性が高く、直接の因果関係とは区別して解釈する必要があります。また、相関が高くても「常に八王子が2℃低い」といった平行な差（バイアス）は存在し得ます。
- **誤答しやすい理由**:  
  相関係数の高さ（連動性）を、「差の有無」や「因果関係」と混同しやすいため。

### 第5問（セクション7配置: 分割表と条件付き確率）
- **問い**:  
  次の表は、ある冬期（学習用の仮想データ）における「東京都心の降水形態」と「八王子での雪の目安条件（低温かつ高湿度）の成立」を整理したクロス集計表です。  
  **「東京都心が雨だった時間」において、八王子が「雪の目安条件を満たしていた」条件付き割合**を求める式として、正しいものはどれですか。

  | | 八王子：雪条件あり | 八王子：雪条件なし | 合計 |
  |---|---|---|---|
  | **都心：雨** | 30時間 ($A$) | 120時間 ($B$) | 150時間 |
  | **都心：雪** | 10時間 ($C$) | 0時間 ($D$) | 10時間 |
  | **合計** | 40時間 | 120時間 | 160時間 |

- **選択肢**:
  1. $\frac{A}{A + B + C + D} = \frac{30}{160}$
  2. $\frac{A}{A + C} = \frac{30}{40}$
  3. $\frac{A}{A + B} = \frac{30}{150}$
  4. $\frac{A + C}{A + B} = \frac{40}{150}$
- **正答**: **3**
- **短い解説**:  
  「東京都心が雨だったとき（事象X）」を条件（分母）とするため、分母は「都心が雨」の行合計（$A + B = 150$）となります。分子はそのうち八王子が雪条件を満たした時間（$A = 30$）となるため、$\frac{30}{150} = 20\%$ です。
- **誤答しやすい理由**:  
  全体の合計（160時間）で割ってしまったり、列合計（雪条件ありの40時間）で割ってしまったりと、条件付き確率の「分母（条件となる母集団）」の設定を誤りやすいため。
